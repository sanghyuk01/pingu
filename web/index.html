A LITTLE FIELD GUIDE

핑구와 친해지기

작은 신호를 주고받으며, 연결의 상태를 살펴요.

01
주소를 알려 주세요

IP·호스트 이름은 ICMP ping으로, URL은 HTTP 응답으로 확인해요. HTTP는 200~299 응답을 성공으로 판단해요.

02
간격과 시간을 정해 주세요

검사는 서버에서 실행되므로 화면을 닫아도 계속돼요. 대상들의 첫 검사는 한 간격 안에 분산해서 시작해요.

03
연결 소식을 확인하세요

대상마다 최근 60건과 누적 통계를 보관해요. 응답시간 통계는 성공한 검사 기준이에요.

검사 결과는 메모리에만 보관돼요. 서버를 재시작하면 결과는 초기화되고 진행 중인 작업은 중단돼요. 종료 작업은 24시간 후 정리해요. ICMP 무응답만으로 서버 장애를 확정할 수는 없어요.
